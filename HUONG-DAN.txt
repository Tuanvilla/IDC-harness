BO CAI IDC HARNESS - PHAN FILE NHI PHAN + WORKFLOW (Muse khong day qua cong ket noi duoc)

Thu tu lam:
1. Xoa release cu tren web TRUOC: https://github.com/Tuanvilla/IDC-harness/releases/tag/desktop
   -> nut Delete o goc tren ben phai cua release -> xac nhan. (Ca tag desktop neu GitHub hoi.)
2. Giai nen goi nay vao D:\IDC-harness (giu nguyen cau truc thu muc: packaging\assets\... va .github\workflows\...)
3. Trong PowerShell tai D:\IDC-harness:
   git add -A
   git commit -m "Bo cai IDC Harness: icon + workflow dong goi"
   git push origin main
4. Vao tab Actions xem run "Desktop installers": chay khoang 20-50 phut (co buoc cai that de kiem tra).
   Neu thay 1 run do xuat hien truoc do thi bo qua (do workflow cu chua khop).
   Run sau khi anh day goi nay moi la run quyet dinh.
5. Xong: muc Releases se co "IDC Harness - Windows & macOS installers" voi 2 file
   IDC-Harness-Setup.exe va IDC-Harness-macOS.dmg - tai ve cai la ra IDC Harness (clone tu repo cua anh, cong 6868).
